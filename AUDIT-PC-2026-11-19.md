# Проверка ПК-версии 3.4.5 — 19.11.2026

Рабочая папка: «Карта сети GPT». Исходная «Карта сети» не изменялась. Пользовательские объекты и учётные записи не переписывались. Все сценарии редактирования выполнялись во временных профилях.

## Исправлено

- Из меню ПК удалена «Карта без интернета». Справка обновлена. Android сохраняет меню и спутник.
- На ПК подключается только схема Херсонской и Запорожской областей. Сервер не выдаёт старую растровую подложку, спутник и прежний кэш; архив старой растровой карты больше не открывается при запуске. Сканирование и установка карт ПК ограничены векторными файлами выбранных областей.
- Офлайн-схема пересобрана: 126847 плиток уровней 0–15, 116852108 байт. Исключены плитки, не пересекающие две области. Добавлены 1480 недостающих плиток на краях; недоступных исходных плиток не осталось. Данные взяты из той же сборки Protomaps 20261113, геометрия внутри области не упрощалась.
- Приграничные и обзорные плитки могут содержать соседние территории. Точная локальная маска закрывает их; Крым не отображается. Границы: geoBoundaries UKR ADM1, OSM/Wambacher, 2017, ODbL. Исходник: https://github.com/wmgeolab/geoBoundaries/tree/9469f09/releaseData/gbOpen/UKR/ADM1. Генератор: tools/prepare_coverage.py.
- За пределами покрытия есть кнопка возврата к схеме. Отсутствующий файл или невозможность запуска WebGL объясняются сообщением вместо пустой карты.
- На масштабах приложения 18–19 адреса из исходного файла не подавляются соседними подписями. На меньших масштабах остаётся устранение наложений для читаемости. Отсутствующие в источнике номера не придуманы.
- Устранено чрезмерное сжатие кнопок пользователей и удалённого доступа при узком окне/крупном тексте. Ограничена плашка координат, добавлен видимый клавиатурный фокус, линейка на ПК не занимает пустую панель во всю высоту.
- Esc и Ctrl+Z в модальных окнах не воздействуют на редактор под ними. Новое окно не наследует позицию прокрутки предыдущего.
- Выход удалённого пользователя читает тело POST перед ответом: устранена причина сброса соединения на Windows при непрочитанном теле запроса.
- Спутниковые материалы перенесены в apk/offline-materials, исключены из активного map и из Git. Обновлён архив Офлайн-схема_Херсон_Запорожье.zip: 117089519 байт, CRC проверена. Архив содержит карту, метаданные, контрольную сумму, маску границ и инструкцию; требуется ПК 3.4.5.

## Что не завершено и ограничения

Пользователь дополнительно потребовал русские актуальные подписи с точным соответствием Яндекс Картам. Договора/выгрузки Яндекса нет (подтверждено пользователем). Эта часть не выполнена: текущие подписи остаются OpenStreetMap/Protomaps, name:ru имеет приоритет, при отсутствии используется исходное name, которое может быть на другом языке. Перевод не выдаётся за проверенное название. Массовых замен и копирования базы Яндекса не выполнялось. Условия хранения результатов геокодирования: https://yandex.ru/dev/tariffs/doc/ru/geocoder/terms/. Для точного покрытия нужен пригодный для этого источник данных и процедура обновления; статический офлайн-файл сам не отслеживает последующие переименования.

Проверки не являются гарантией отсутствия любых ошибок: не проводились длительное нагрузочное испытание большого числа клиентов, проверка на всех видеокартах и реальной закрытой сети. Рабочий процесс пользователя автоматически не перезапускался. Изменения в GitHub не отправлялись. Для применения нужно закрыть приложение и его консоль, затем запустить BAT из «Карта сети GPT».
